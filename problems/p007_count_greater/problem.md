# 统计大于 k 的元素个数

给定一个整数列表 `nums` 和一个整数 `k`，返回列表中**严格大于 `k`**（即大于，不包含等于）的元素个数。

- 等于 `k` 的元素不计入。
- 空列表返回 `0`。
- 列表长度 0 到 20，每个元素在 -5 到 5 之间；`k` 也在 -5 到 5 之间。

示例：

- `count_greater([1, 3, 5], 2)` 返回 `2`
- `count_greater([2, 2, 2], 2)` 返回 `0`
- `count_greater([-1, -3], -2)` 返回 `1`
- `count_greater([], 0)` 返回 `0`
