# 前 k 个元素之和

给定一个整数列表 `nums` 和一个整数 `k`，返回列表**前 `k` 个元素的和**。

- 如果 `k` 大于列表长度，就把所有元素相加。
- 如果 `k` 小于等于 0，返回 `0`。
- 列表长度 0 到 8，每个元素在 -5 到 5 之间；`k` 在 -3 到 10 之间（可能为负、为 0、或超过列表长度）。

示例：

- `sum_first_k([1, 2, 3, 4], 2)` 返回 `3`
- `sum_first_k([1, 2, 3], 10)` 返回 `6`
- `sum_first_k([1, 2, 3], 0)` 返回 `0`
- `sum_first_k([1, 2, 3], -1)` 返回 `0`
